# wipeme v0.2.2-alpha.1

Status: preview release.

## User-visible changes

- Terminal QR output now uses the established `github.com/mdp/qrterminal/v3`
  compact half-block renderer instead of a custom ANSI color renderer.
- QR output no longer forces black or bright-white ANSI backgrounds, avoiding
  gray or theme-dependent background panels in terminals and asciinema playback.
- `wipeme --qr --qr-invert` swaps module glyphs for terminals with the opposite
  foreground/background orientation.
- Link output, JSON behavior, encryption, message creation, and link formats are
  unchanged from `v0.2.1-alpha.1`.

QR codes are bearer capabilities. Automatic-key QR codes contain the complete
private link and fragment secret. Treat terminal recordings, screenshots, logs,
and streams containing them as secrets.

## Compatibility

- Encrypted envelope: v1, unchanged.
- Go SDK: `github.com/wipe-me/sdk/go@v0.5.0-alpha.1`, unchanged.
- Backend API: unchanged.
- Link formats: automatic `3-3-3#3-3-3-3` and manual `4-4`, unchanged.
- Supported release targets: macOS and Linux on AMD64 and ARM64.

## Release validation

- Run `go test ./...` and `go vet ./...`.
- Confirm the terminal QR round-trip test decodes the complete link with an
  independent QR decoder.
- Confirm `wipeme --version` reports `0.2.2-alpha.1-dev` before tagging.
- Confirm a tagged build reports exactly `0.2.2-alpha.1`.
- Create normal and inverted QR output on both light and dark terminal themes.
- Confirm `wipeme --json --qr` fails without contacting the service.
- Verify the GitHub archives, Homebrew cask, `.deb`, `.rpm`, APT preview repository,
  and RPM preview repository all contain the tagged binary.
