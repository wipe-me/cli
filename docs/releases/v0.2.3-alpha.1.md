# wipeme v0.2.3-alpha.1

Status: preview release.

## User-visible changes

- Terminal QR output uses `github.com/mdp/qrterminal/v3`'s native compact
  `HalfBlocks` mode with its standard glyphs and four-module quiet zone.
- Compact output includes a caption explaining that it requires a Unicode terminal
  with block-character support and a monospaced font, and points to `--qr-big` if
  it is distorted or unreadable.
- `wipeme --qr-big` provides the library's native full-size renderer as a
  compatibility fallback. It cannot be combined with `--qr`.
- No CLI-specific ANSI colors, cell renderer, or output post-processing is applied.
- `--qr-invert` works with either QR renderer and only swaps the library's standard
  module glyphs for the opposite terminal background.
- Link output, JSON behavior, encryption, message creation, and link formats are
  unchanged from `v0.2.2-alpha.1`.

QR codes are bearer capabilities. Automatic-key QR codes contain the complete
private link and fragment secret. Treat terminal recordings, screenshots, logs,
and streams containing them as secrets.

## Compatibility

- Encrypted envelope: v1, unchanged.
- Go SDK: `github.com/wipe-me/sdk/go@v0.5.0-alpha.1`, unchanged.
- Backend API: unchanged.
- Link formats: automatic `3-3-3#3-3-3-3` and manual `4-4`, unchanged.
- Supported release targets: macOS and Linux on AMD64 and ARM64.

## Release validation

- Run `go test ./...` and `go vet ./...`.
- Confirm the terminal QR round-trip test decodes the complete link with an
  independent QR decoder.
- Confirm `wipeme --version` reports `0.2.3-alpha.1-dev` before tagging.
- Confirm a tagged build reports exactly `0.2.3-alpha.1`.
- Create normal and inverted QR output on both light and dark terminal themes.
- Confirm `wipeme --json --qr` fails without contacting the service.
- Confirm `wipeme --json --qr-big` and `wipeme --qr --qr-big` fail without
  contacting the service.
- Verify the GitHub archives, Homebrew cask, `.deb`, `.rpm`, APT preview repository,
  and RPM preview repository all contain the tagged binary.
