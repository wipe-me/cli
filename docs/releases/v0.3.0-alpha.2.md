# wipeme v0.3.0-alpha.2

Status: development preview.

## User-visible changes

- Adds the agent-safe local stdio MCP server introduced in `v0.3.0-alpha.1`,
  including host and restricted access modes, recovery-safe environment-file
  injection, process execution, file output, policy inspection, and inline PNG QR
  output.
- Fixes MCP file and recovery paths on macOS, where `/var` is an operating-system
  alias for `/private/var`. Allowed roots and output parents are now compared after
  canonical resolution while final file and recovery-directory symlinks remain
  rejected.
- Supersedes `v0.3.0-alpha.1`, whose macOS CI job failed on temporary paths beneath
  that system alias. Linux behavior, encrypted envelopes, links, SDK integration,
  and the backend API are unchanged.

## Compatibility

- Encrypted envelope: v1, unchanged.
- Go SDK: `github.com/wipe-me/sdk/go@v0.5.0-alpha.1`, unchanged.
- MCP Go SDK: `github.com/modelcontextprotocol/go-sdk@v1.7.0`.
- Supported release targets: macOS and Linux on AMD64 and ARM64.

## Release validation

- Run `gofmt`, `go test ./...`, `go test -race ./...`, and `go vet ./...` natively
  on macOS and on Linux.
- Confirm MCP reads and writes work through canonicalized allowed roots.
- Confirm a recovery directory beneath the macOS `/var` alias works, while a
  recovery directory whose final component is a symlink is rejected.
- Confirm `wipeme mcp --version` reports `0.3.0-alpha.2-dev` before tagging and the
  tagged binary reports exactly `0.3.0-alpha.2`.
- Verify all release assets and package repositories before publishing the
  prerelease Homebrew cask.
