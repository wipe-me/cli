# wipeme v0.3.0-alpha.3

Status: development preview.

## User-visible changes

- Adds the agent-safe local stdio MCP server and the macOS path canonicalization
  fix prepared in the preceding `v0.3.0` prerelease candidates.
- Preserves fail-closed restricted-mode behavior for nonexistent read paths by
  canonicalizing and validating their existing parent before inspecting the final
  path.
- Supersedes `v0.3.0-alpha.2`, whose release workflow stopped in Linux tests before
  creating release assets. Encrypted envelopes, private links, SDK integration,
  and the backend API remain unchanged.

## Compatibility

- Encrypted envelope: v1, unchanged.
- Go SDK: `github.com/wipe-me/sdk/go@v0.5.0-alpha.1`, unchanged.
- MCP Go SDK: `github.com/modelcontextprotocol/go-sdk@v1.7.0`.
- Supported release targets: macOS and Linux on AMD64 and ARM64.

## Release validation

- Run `gofmt`, `go test ./...`, `go test -race ./...`, and `go vet ./...` natively
  on macOS and in Linux.
- Confirm canonical macOS `/var` paths work within configured roots.
- Confirm nonexistent paths outside configured roots fail as
  `path_outside_allowed_root` without revealing their filesystem state.
- Confirm `wipeme mcp --version` reports `0.3.0-alpha.3-dev` before tagging and the
  tagged binary reports exactly `0.3.0-alpha.3`.
- Verify CI, release assets, package repositories, and checksums before publishing
  the prerelease Homebrew cask.
